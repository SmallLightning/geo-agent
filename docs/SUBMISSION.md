## 三、作品简介（200 字，可直接贴）

用户说一句「从杭州东站出发，找家人均 100 以内、评分 4.5 以上、走路能到的餐厅，要前 3 家」，系统会把它拆成 6 个结构化条件，调用高德开放平台的 POI 周边检索、路径规划和地理编码，输出带评分、人均消费、步行/骑行/驾车时间的地点清单。

技术上有三个关键点：一是**地标消歧**——「西湖」默认会命中台湾苗栗县西湖乡，系统用地标→城市映射把常见歧义地名纠正到正确城市；二是**出行方式自适应**——按直线距离在步行（<1km）、骑行（1–3km）、驾车（>3km）之间自动切换，避免出现「536 米的路驾车 13 分钟」这种荒谬结果；三是**可降级**——大模型不可用时退回正则解析，没有 API Key 时退回录制快照，任何机器 clone 下来都能跑通。

## 六、运行方式

```bash
git clone https://github.com/SmallLightning/geo-agent
cd geo-agent
./run.sh
```

不需要任何 Key。要跑实时数据时，把高德 Web 服务 Key 写进 `.env` 的 `AMAP_KEY` 即可。
